Lecture 3: Implementing simulations

DATA 352/551: Modeling and Simulation

Recommended workflow for simulations

  1. Write a dedicated function for one simulation

Input: parameters of the ONE simulation Output: a single result (i.e., “what do you want to save after ONE simulation?”)

  1. Test the function with a few calls to make sure it works as expected

  2. Initialize global simulation parameters

How many simulations do you want to run? How should the results be stored? Important: should always pre-allocate a vector (e.g. rep(NA, 10000)) to store results, rather than appending to a vector each time

  1. Repeat the function many times

Can use a for loop, or functional wrappers like replicate() (in R), or functions that can handle parallelization (i.e., use multiple cores on your computer to run simulations faster)

Example: outcome of a fair die

What is the expected value of the outcome of a fair die? Design and implement a simulation to find out.

# 1. ONE simulation function
sim_die <- function(n = 6) {
  return(sample(1:n,size=1))
}

# 2. Test the function
sim_die()
[1] 2
# 3. Initialize global simulation parameters
NSIM <- 10000
result <- rep(NA, NSIM)

# 4. Repeat the simulation NSIM times

#### Method 1: 'for' loop
for(i in 1:NSIM) {
  result[i] <- sim_die()
}
mean(result)
[1] 3.5158
#### Method 2: Base R replicate()
result <- replicate(NSIM, sim_die())
mean(result)
[1] 3.4877
#### Method 3: parallel processing (optional)
library(parallel)
cl <- makeCluster(2) # use 2 cores
clusterExport(cl, "sim_die")
result <- parSapply(cl, 1:NSIM, function(i) sim_die())
stopCluster(cl)
mean(result)
[1] 3.5218

Note: Method 1 and Method 2 are computational similar (provided that the result vector is pre-allocated). Method 3 is more advanced and can be significantly faster for very large simulations.

R review

Functions

An R function is a named piece of code that takes inputs, does some work, and returns an output.

function_name <- function(input1, input2 = default_value) {
  # code that uses the inputs to generate result
  return(result)
}

  • Give the function a descriptive name.

  • Put the inputs in the parentheses, with defaults when useful.

  • Write the calculation inside the braces.

  • The last expression is returned automatically; return() is optional.

  • To return more than one value, you can put the values in a list.

  • Basic example 1:

square_plus_one <- function(x) {
  return(x^2 + 1)
}

square_plus_one(3)
# 10
  • Basic example 2:
summarize_values <- function(first_value, second_value, third_value = 10) {
  result <- list(
    total = first_value + second_value + third_value,
    average = (first_value + second_value + third_value) / 3
  )
  return(result)
}

summarize_values(4, 8)
# $total
# [1] 22
#
# $average
# [1] 7.333333

If statements

An if statement allows you to run a chunk of code only when a condition is true. It is often used together with loops.

Basic structure in R:

if (condition) {
  # code to run when the condition is TRUE
}

You might need multiple if statements to cover more than one condition. You can also use an else statement.

Example: We roll a fair die. If the outcome is 6, we win $20; if the outcome is 4 or 5, we win $10; otherwise we lose $15. Is this a fair game? How much would you expect to win or lose? Write a function to play this game one time.

Show solution 
play_game <- function() {
  outcome <- sample(1:6, size = 1)

  if (outcome == 6) {
    result <- 20
  } else if (outcome %in% c(4, 5)) {
    result <- 10
  } else {
    result <- -15
  }

  return(result)
}

# One play
play_game()
[1] -15
# Approximate expected value by simulating many plays
NSIM <- 10000
result <- rep(NA, NSIM)
result <- replicate(NSIM, play_game())
mean(result)
[1] -0.69

For comparison, the expected value is

\[ E[X] = \frac{1}{6}(20) + \frac{2}{6}(10) + \frac{3}{6}(-15) = \frac{20 + 20 - 45}{6} = -\frac{5}{6} \approx -0.83. \]

So this is not a fair game: on average, you lose about $0.83 in the long run.

Loops

Loops are used to repeat a chunk of code.

  • for loop: repeat a fixed number of times
  • while loop: repeat until a condition is met

For loops

Basic example:

for (i in 1:5) {
  print(i)
}
  • A for loop has an index and a code chunk. For example, if the index is \(i = 1, 2, 5\), then the code chunk runs with \(i = 1\), then with \(i = 2\), and then with \(i = 5\). The index (i in the above example) does not need to be created separately.

While loops

Basic example:

x <- 1
while (x < 5) {
  print(x)
  x <- x + 1
}

A while loop has three ingredients:

  • initialization
  • condition
  • code chunk that updates the condition

The code runs as long as the condition is met. This is useful when the number of repetitions is not known in advance.

  • It is important to properly update the objects involved in the while-loop condition.
  • It is also recommended to set a safety upper bound so the loop cannot run forever.
x <- 0
count <- 0
while (x < 5 && count < 1000) {
  x <- x + 1
  count <- count + 1
}
