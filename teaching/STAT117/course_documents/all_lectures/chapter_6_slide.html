Regression line

The goal is to find the line that “best fits” the data. The (least squares) regression line minimizes the total “distance” of each point to the line (where distance is measured by the squared difference).

R code (optional) 
nels <- haven::read_sav("../../../../dataset/NELS.sav")

plot(
  nels$achmat08,
  nels$ses,
  xlab = "Math achievement in 8th grade (achmat08)",
  ylab = "SES",
  pch = 16
)

abline(lm(ses ~ achmat08, data = nels), col = "#D36B43", lwd = 3)
