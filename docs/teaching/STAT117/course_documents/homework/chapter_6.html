Exercise 6.1

In Exercise 5.6, we used the States data set to determine that there was a positive linear relationship between EDUCEXPE, the average educational expenditure per pupil, and TEACHPAY, the average salary of public school teachers in the state. In this exercise, create and interpret a model to predict EDUCEXPE from TEACHPAY.

  1. Verify that regression is appropriate in this case.
  2. Find the regression equation for predicting EDUCEXPE from TEACHPAY.
  3. Interpret the value of the slope in context, using language that someone who has not taken statistics would understand.
  4. Interpret the value of the intercept in context, or indicate why it is not meaningful.
  5. What is the predicted educational expenditure for a state with teacher pay of $40,000?
  6. Is it appropriate to use the regression equation to predict educational expenditure for a state with teacher pay of $80,000?
  7. Report the value of \(R\) and interpret it in context.
Show solution
  1. EDUCEXPE and TEACHPAY are scale/ratio variables, and the scatterplot indicates that the pattern is effectively approximated by a line.
  2. \(\widehat{EDUCEXPE} = 0.276(TEACHPAY) - 3372.988\).
  3. A one-dollar increase in average teacher salary corresponds to an average increase of about 28 cents in per-pupil educational expenditure.
  4. The intercept is not meaningful because no state’s average teacher salary is close to $0.
  5. \(0.276(40{,}000) - 3372.988 = \$7{,}667.01\).
  6. No. \(80{,}000\) is well beyond the largest teacher salary value in the data used to create the model.
  7. \(R = .72\), indicating a strong correlation between actual and predicted educational expenditures.

Exercise 6.3

Using the NELS data set, investigate whether twelfth-grade math achievement (ACHMAT12) can be predicted from eighth-grade socioeconomic status (SES). Create a scatterplot of ACHMAT12 by SES with the regression line and use the results to answer the following.

  1. Determine whether regression is appropriate for predicting ACHMAT12 from SES.
  2. What is the regression equation?
  3. Is there a meaningful interpretation of the slope? If so, explain what additional information it provides.
  4. Is there a meaningful interpretation of the y-intercept? If so, explain what additional information it provides.
  5. What is the predicted twelfth-grade math achievement score for a student with SES = 20?
  6. For the first student in the NELS data set (ID = 1), what is the actual twelfth-grade math achievement score?
  7. For this student, what is the predicted twelfth-grade math achievement score?
Show solution
  1. Both variables are interval-level, and the scatterplot pattern is sufficiently modeled by a line.
  2. \(\widehat{ACHMAT12} = 0.368(SES) + 50.123\).
  3. Each one-point increase in SES is associated with an average increase of 0.368 points in twelfth-grade math achievement.
  4. A student with SES = 0 is predicted to score 50.123 in twelfth-grade math achievement.
  5. The predicted score is 57.483.
  6. The actual score is 59.69.
  7. The predicted score is 58.59.

Exercise 6.4

Use the Impeach data set to perform a simple linear regression analysis predicting a senator’s conservatism (CONSERVA) from the state voter support for Clinton (SUPPORTC).

  1. Create a scatterplot and verify that the data have an approximately linear shape.
  2. What is the correlation, \(r\), between conservatism and state voter support for Clinton?
  3. What is the value of \(R\), a measure of the goodness of fit? Describe the goodness of fit.
  4. Write the regression equation for predicting conservatism (\(Y\)) from state voter support for Clinton (\(X\)).
  5. Interpret the slope in context.
  6. Interpret the y-intercept, or explain why it is not meaningful.
  7. Use the regression equation to predict conservatism for a senator whose state gave Clinton 50 percent of the vote in the 1996 presidential election.
Show solution
  1. The shape is not exactly linear, but no other simple curve provides a better approximation.
  2. \(r = -.447\).
  3. \(R = .447\), indicating a moderate-to-strong goodness of fit.
  4. \(\widehat{CONSERVA} = -2.488(SUPPORTC) + 164.911\).
  5. Each one-percentage-point increase in state voter support for Clinton is associated with an average 2.488-point decrease in the senator’s conservatism rating.
  6. The intercept is not meaningful because the data include no states with voter support near zero; the lowest support value was above 30%.
  7. \(-2.488(50) + 164.911 = 40.51\).

  2. Is the slope positive, negative, or near zero? What does that tell you about the relationship?

Exercise 6.13

In this exercise, use the NELS data set to create a model predicting socioeconomic status (SES) from eighth-grade computer ownership (COMPUTER), a dichotomous variable. Part (a), the scatterplot task, is omitted as requested.

  1. What is the regression equation for predicting SES from computer ownership?
  2. Interpret the slope in context.
  3. Interpret the intercept in context, or explain why it is not meaningful.
  4. Use the equation to predict SES for those who owned a computer in eighth grade.
  5. Use the equation to predict SES for those who did not own a computer in eighth grade.
  6. Use Jamovi to find the mean SES of those who did and did not own a computer in eighth grade.
  7. If COMPUTER were recoded as COMP1, with 1 = did not own and 2 = did own, what would the regression equation be?
  8. If COMPUTER were recoded as COMP2, with 1 = did not own and 0 = did own, what would the regression equation be?
  9. Is it ever not meaningful to interpret the intercept when the independent variable is dichotomous?
Show solution
  1. \(\widehat{SES} = 4.83(COMPUTER) + 16.144\).
  2. Students who owned a computer in eighth grade have an average SES 4.83 points higher than those who did not.
  3. The intercept, 16.14, is the predicted mean SES for students who did not own a computer in eighth grade (COMPUTER = 0).
  4. For owners, the predicted SES is \(4.83(1) + 16.144 = 20.97\).
  5. For non-owners, the predicted SES is \(4.83(0) + 16.144 = 16.14\).
  6. Comparing means gives those same group means: 20.97 for computer owners and 16.14 for non-owners.
  7. \(\widehat{SES} = 4.83(COMP1) + 11.31\).
  8. \(\widehat{SES} = -4.83(COMP2) + 20.97\).
  9. Yes. The intercept is meaningful when one category is coded 0. If neither category is coded 0, the intercept does not represent either group’s mean.

Exercise 6.20

During the semester, students in a statistics class provided their average weekly study time and course grade (on a 0.0-to-4.0 scale). The regression equation for predicting grade from hours studied was \(\widehat{Y} = 1.2X + 0.3\). If a student studies 3 hours per week on average, what is her predicted numerical course grade?

  1. 2.25
  2. 3.90
  3. 3.60
  4. Cannot be determined from the data
Show solution
  1. \(1.2(3) + 0.3 = 3.90\).
