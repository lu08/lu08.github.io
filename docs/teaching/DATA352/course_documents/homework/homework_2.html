Question 1

Suppose a random variable \(X\) can take values \(\{1,2,3\}\) with probabilities \(\{0.2,0.3,0.5\}\).

  1. Simulate 10,000 observations from the distribution of \(X\). Calculate the mean of the simulated draws.
  2. Calculate \(E(X)\) mathematically and compare it with the simulated mean.
  3. Simulate another 10,000 observations using only random draws from a uniform distribution on \((0,1)\). In R, do not use sample; use runif instead.
Show solution

The expected value is

\[ E(X)=1(0.2)+2(0.3)+3(0.5)=2.3. \]

The simulated mean should be close to 2.3.

simulated_x <- sample(1:3, size = 10000,
                      prob = c(0.2, 0.3, 0.5), replace = TRUE)
mean(simulated_x)

For the uniform-draw version, use intervals with lengths equal to the desired probabilities: \(X=1\) if \(U<0.2\), \(X=2\) if \(0.2\le U<0.5\), and \(X=3\) otherwise.

uniform_draws <- runif(10000)
simulated_x <- uniform_draws
simulated_x[uniform_draws < 0.2] <- 1
simulated_x[uniform_draws >= 0.2 & uniform_draws < 0.5] <- 2
simulated_x[uniform_draws >= 0.5] <- 3
mean(simulated_x)

Question 2

There is a 2% click rate for an online advertisement. The number of people who click among the next 100 people can be modeled by a binomial distribution.

  1. What are the parameters of the binomial distribution?
  2. Discuss the binomial model assumptions in this context.
  3. Calculate the probability that exactly two people click, that no one clicks, and that five or fewer people click.
Show solution

Let \(X\) be the number of clicks. Then \(X\sim\operatorname{Binomial}(n=100,p=0.02)\). The model assumes independent clicks and the same click probability for every person.

dbinom(2, size = 100, prob = 0.02)
dbinom(0, size = 100, prob = 0.02)
pbinom(5, size = 100, prob = 0.02)

Independence might fail if people influence one another. The common-probability assumption might fail if different groups have different click rates.

Question 3

The number of sixes obtained when rolling a fair six-sided die five times can be modeled by a binomial distribution.

  1. What are the parameters of the binomial distribution?
  2. Discuss the binomial model assumptions. If the die were biased, could a binomial distribution still be used?
  3. What is the probability of getting more than two sixes in five rolls?
  4. Design a simulation to verify your answer using the four steps from Lecture 1.
Show solution

Let \(X\) be the number of sixes. Then \(X\sim\operatorname{Binomial}(n=5,p=1/6)\). The rolls must be independent, and the probability of rolling a six must remain constant. A biased die can still use a binomial model if that probability is constant from roll to roll.

\[ P(X>2)=1-P(X\le 2). \]

1 - pbinom(2, size = 5, prob = 1 / 6)

For a simulation: roll the die five times, record the number of sixes, repeat many times, and estimate \(P(X>2)\) by the proportion of repetitions with more than two sixes.

number_of_sixes <- numeric(10000)
for (simulation in seq_len(10000)) {
  rolls <- sample(1:6, size = 5, replace = TRUE)
  number_of_sixes[simulation] <- sum(rolls == 6)
}
mean(number_of_sixes > 2)

Question 4

A typesetter makes, on average, one mistake per 1,000 words. Let \(X\) be the number of mistakes on a page with \(n\) words.

  1. Suppose \(X\) follows a binomial distribution. What are the parameters? Discuss the assumptions.
  2. Using a binomial model, calculate the probabilities of no mistakes and exactly one mistake on a 100-word page, one or more mistakes on a 100-word page, and no mistakes on a 200-word page.
  3. Suppose \(X\) follows a Poisson distribution. What is the parameter? Discuss the assumptions.
  4. Recalculate the probabilities using a Poisson model.
  5. Simulate 1,000 observations from both models and compare their histograms.
Show solution

For the binomial model, each word is a trial with mistake probability \(p=0.001\), so \(X\sim\operatorname{Binomial}(n,0.001)\). The assumptions are independent mistakes and the same mistake probability for every word.

dbinom(0, size = 100, prob = 0.001)
dbinom(1, size = 100, prob = 0.001)
1 - dbinom(0, size = 100, prob = 0.001)
dbinom(0, size = 200, prob = 0.001)

For the Poisson model, \(\lambda=0.001n\). It assumes independent mistakes occurring at a constant average rate.

dpois(0, lambda = 0.1)
dpois(1, lambda = 0.1)
1 - dpois(0, lambda = 0.1)
dpois(0, lambda = 0.2)

The models should give similar probabilities because \(n\) is relatively large and \(p\) is small.

par(mfrow = c(1, 2))
hist(rbinom(1000, size = 100, prob = 0.001),
     main = "Binomial", xlab = "Mistakes", col = "lightblue")
hist(rpois(1000, lambda = 0.1),
     main = "Poisson", xlab = "Mistakes", col = "purple")

Question 5

Read Question 18 on page 199 of Introduction to Probability (copied below) and answer its parts using appropriate probability models.

18. A baker blends 600 raisins and 400 chocolate chips into a dough mix and, from this, makes 500 cookies.

  1. Find the probability that a randomly picked cookie will have no raisins.
  2. Find the probability that a randomly picked cookie will have exactly two chocolate chips.
  3. Find the probability that a randomly chosen cookie will have at least two bits (raisins or chips) in it.
Show solution

For the raisin-count calculations, use Poisson and binomial models as appropriate. The Poisson mean is the average number of raisins per cookie.

For part (a), \(\lambda=600/500=6/5\):

dpois(0, lambda = 6 / 5)
dbinom(0, size = 600, prob = 1 / 500)

For part (b), \(\lambda=400/500=4/5\):

dpois(2, lambda = 4 / 5)

For part (c), \(\lambda=1000/500=2\):

1 - ppois(1, lambda = 2)

The binomial and Poisson answers should be close because the number of trials is large and the success probability is small.

Question 6

Under the setup of Question 26 on page 201 of Introduction to Probability (copied below), the number of hits in each of 576 small areas can be modeled by a Poisson distribution. What is the parameter? Calculate the probabilities that an area has 0, 1, 2, 3, 4, and 5 or more hits, and compare them with the actual proportions.

26. Feller discusses the statistics of flying bomb hits in an area in the south of London during the Second World War. The area in question was divided into \(24\times24=576\) small areas. The total number of hits was 537. There were 229 squares with 0 hits, 211 with 1 hit, 93 with 2 hits, 35 with 3 hits, 7 with 4 hits, and 1 with 5 or more. Assuming the hits were purely random, use the Poisson approximation to find the probability that a particular square would have exactly \(k\) hits. Compute the expected number of squares that would have 0, 1, 2, 3, 4, and 5 or more hits and compare this with the observed results.

Show solution

The Poisson parameter is \(\lambda=537/576\).

probability <- dpois(0:4, lambda = 537 / 576)
probability <- c(probability, 1 - ppois(4, lambda = 537 / 576))

expected <- 576 * probability
actual <- c(229, 211, 93, 35, 7, 1)

comparison <- cbind(expected, actual)
rownames(comparison) <- c(
  "0 hits", "1 hit", "2 hits", "3 hits", "4 hits", "5 or more hits"
)
round(comparison, 1)

The expected and actual counts should be close, indicating that the Poisson model fits these data reasonably well.

Question 7

Suppose the probabilities of a male and a female child are both 0.5, and twins are not considered. Calculate the following probabilities using appropriate models.

  1. If you plan to have three children, what is the probability of exactly one daughter? What is the probability of at least one daughter?
  2. What is the probability that your first daughter is your third child?
  3. What is the probability that your second daughter is your third child?
  4. How many children do you need to have more than a 95% chance of at least one daughter?
Show solution

For part 1, use \(X\sim\operatorname{Binomial}(3,0.5)\):

dbinom(1, size = 3, prob = 0.5)
1 - dbinom(0, size = 3, prob = 0.5)

For part 2, two sons followed by a daughter means two failures before the first success:

dgeom(2, prob = 0.5)

For part 3, one son followed by two daughters means one failure before the second success:

dnbinom(1, size = 2, prob = 0.5)

For part 4, find the smallest \(M\) such that \(1-P(X=0)>0.95\) for \(X\sim\operatorname{Binomial}(M,0.5)\). The smallest value is \(M=5\).

1 - pbinom(0, size = 1:10, prob = 0.5)
