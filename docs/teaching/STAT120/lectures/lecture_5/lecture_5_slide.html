Lecture 5: data visualization

Data: the changing childhood project by UNICEF

Prep work

Today’s data comes from The Changing Childhood Project (conducted by UNICEF). The New York Times published an intresting article based on this dataset.

  • Survey data with around 1000 respondents per country from 21 countries
  • Two age cohorts: young (15-24) vs old (40 or older)
  • Most variables are Likert Scale; naming is not very intuitive (see codebook)

df.child <- read_csv("../../../../dataset/unicef-changing-childhood-data.csv")

# create a smaller dataset for simplicity
df.child.small <- df.child %>%
  filter(COUNTRYNEW %in% c("United States", "Japan", "Nigeria")) %>%
  select(COUNTRYNEW, AGE, WP22110, WP22109, WP30, WP22091)
  • COUNTRYNEW: respondent’s country.
  • AGE: respondent’s age group (the survey compares ages 15-24 with ages 40 and older).
  • WP22110: minimum acceptable age for men to get married. 97 means 97 or older; 98 is “Don’t know”; 99 is “Refused”.
  • WP22109: minimum acceptable age for women to get married. 97 means 97 or older; 98 is “Don’t know”; 99 is “Refused”.
  • WP30: satisfaction with standard of living: 1 = satisfied, 2 = dissatisfied, 3 = “Don’t know”, 4 = refused.
  • WP22091: which group the respondent most identifies with: 1 = city or area where they live, 2 = their country, 3 = the world, 8 = “Don’t know”, 9 = refused.

ggplot

Introduction

  • ggplot2 is an alternative framework for creating plots and graphics; the package is loaded as part of tidyverse
Feature ggplot2 Base R plot functions
Syntax Unified, intuitive syntax (the “grammar of graphics”) Syntax depends on the plot type, such as plot() or hist()
Storing plots Plots can be stored as ggplot objects Plots are drawn directly rather than stored as R objects
Adding layers Add layers to an existing plot with + Add to the current plot with additional plotting commands

Example 1

df.child.small %>%
  filter(WP22110 < 97, WP22109 < 97) %>%
  ggplot(aes(x=WP22110, y=WP22109, color=COUNTRYNEW)) +
  geom_point() +
  theme_bw() +
  labs(x="Minimum acceptable age for men", y="Minimum acceptable age for women", color="Country")

Example 2

df.child.small %>%
  filter(WP22110 < 97, WP22109 < 97) %>%
  ggplot(aes(x = COUNTRYNEW, y = WP22110)) +
  geom_boxplot() +
  theme_bw() +
  labs(x="Country", y="Minimum acceptable age for men")

Basic ingredients of a ggplot

  1. Data
    • Data frame containing all the raw observations
  2. Aesthetic mapping
    • An aesthetic is a visual property of the plot, such as x-axis, y-axis, color, size, etc.
    • Use aes to specify which variable is mapped to which aesthetic
    • Example: minimum acceptable age for men -> x-axis; minimum acceptable age for women -> y-axis; country -> color
  3. Geoms
    • What types of layers should be added to the plots

Example 1 explained

ggplot(
  data=subset(df.child.small, WP22110 < 97 & WP22109 < 97), # data
  mapping=aes(
    x=WP22110, # minimum acceptable age for men maps to the x-axis
    y=WP22109, # minimum acceptable age for women maps to the y-axis
    color=COUNTRYNEW)) + # country maps to color
  geom_point() # add a scatterplot geom

Example 2 explained

ggplot(data=subset(df.child.small, WP22110 < 97), # data
    mapping=aes(x=COUNTRYNEW, # country maps to the x-axis
      y=WP22110)) + # minimum acceptable age for men maps to the y-axis
  geom_boxplot() # add a boxplot geom

Layering and Customization to ggplot

Customize ggplot with +

ggplot offers a very convenient syntax (+) to add elements and layers

df.child.small %>%
  filter(WP22110 < 97, WP22109 < 97) %>%
  ggplot(aes(x=WP22110, y=WP22109, color=WP22110)) +
  geom_point() +
  theme_bw() +
  ggtitle('Marriage-age views by country') +

Example

WP22091 records whether respondents identify most with their city or area (1), their country (2), or the world (3). WP30 records satisfaction with standard of living: satisfied (1) or dissatisfied (2).

df.child %>%
  filter(COUNTRYNEW %in% c("Germany", "United States"),
         WP22091 %in% 1:3, WP30 %in% 1:2) %>%
  ggplot(aes(x = as.factor(WP22091), y = as.factor(WP30))) +
  geom_jitter() +
  theme_bw() +
  facet_wrap(~COUNTRYNEW) +
  ggtitle("Identity and standard-of-living satisfaction") +
  labs(
    x = "Identity (1 = city/area, 2 = country, 3 = world)",
    y = "Standard of living (1 = satisfied, 2 = dissatisfied)"
  )

Interactive plots

Interactive plots

  • Wide variety, very flexible; can generate quite complicated graphs (for example, see HTML widgets)
  • Many new packages and functions are being published (esp. on github)
  • Currently, no “go-to” package, no unified approach
  • We’ll try a few simple examples to give you an idea, mostly using the plotly package
#install.packages('plotly')
library(plotly)

Example 1: Histogram

  • Note the difference in syntax convention (e.g.: ~ varname)
plot_ly(data=filter(df.child.small, WP22110 < 97),
        x=~WP22110, type='histogram') %>%
  layout(xaxis=list(title="Minimum acceptable age for men"))

Example 2: Boxplot

plot_ly(data=filter(df.child.small, WP22110 < 97),
    y=~WP22110, x=~COUNTRYNEW, type='box') %>%
  layout(xaxis=list(title="Country"),
    yaxis=list(title="Minimum acceptable age for men"))

Example 3: 2D scatterplot

plot_ly(data=filter(df.child.small, WP22110 < 97, WP22109 < 97),
  x=~WP22110, y=~WP22109,
  color=~COUNTRYNEW, text=~COUNTRYNEW) %>%
  layout(xaxis=list(title="Minimum acceptable age for men"),
   yaxis=list(title="Minimum acceptable age for women"))

Example 4: 3D scatterplot

plot_ly(data=filter(df.child.small, WP22110 < 97, WP22109 < 97, WP22091 < 4),
  x=~WP22110, y=~WP22109,
  z=~WP22091, text=~COUNTRYNEW,
  color=~COUNTRYNEW, size=I(4)) %>%
    layout(scene=list(xaxis=list(title="Minimum acceptable age for men"),
      yaxis=list(title="Minimum acceptable age for women"),
        zaxis=list(title="Identity (1-3)")))

  • WP22071: whether digital technology helps children with education.
  • WP22072: whether digital technology helps children have fun.
  • For both questions, 1 = a lot, 2 = a little, and 3 = not at all. Other response codes are excluded.

Try to reproduce the following graph. You can also use other variables of your interest (refer to the codebook).

df.child %>%
  filter(WP22071 %in% 1:3, WP22072 %in% 1:3) %>%

    mean_education = mean(WP22071),
