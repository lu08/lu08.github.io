Getting started

Posit cloud

Go to https://posit.cloud/ (you can log in with your Drew account). We’ll first use this online platform to demonstrate RStudio; later we’ll download R and RStudio on your computer.

To start a new script, do File - New File - R Script. Do NOT choose “new project.”

Default layout of RStudio:

  • Upper left (R Script): this is a text file (.R format) that contains all the code you write
  • Lower left (Console): this is where your code is run (i.e., R will provide feedback and result here)
  • Upper right: contains information for the current R session
  • Lower right: contains information for files and packages; plots and help pages will also show up here

Download R and RStudio

RStudio is an Integrated development environment (IDE) for R. You need to download BOTH R and RStudio for RStudio to work.

  • While you can use R without RStudio, the interface is not as nice
  • When you open an R script (recall, this is a .R document), make sure it’s opened in RStudio (to change the default: Right click - Get Info - Open with RStudio - Change All)
  • Have a habit of saving R script often when you are coding
  • When exit RStudio, you should only save the R script (“save workspace image?” - Don’t Save)
  • You can easily upload files to Posit Cloud, or download files from Posit Cloud

Run R code

Running code directly in the console (1% of time):

  • Fast and easy
  • However: nothing is saved; can only run one line at a time

Instead (99% of time):

  • Write code in R scripts
  • Can save the R scripts to run or modify your code in the future
  • Can write many lines of code and run portions of it as needed

Run R code

To run code in the console, you just need to hit enter; when you are writing code in the script, hitting enter will go to the next line but will not run the code.

To run code from R script:

  • if you have any highlighted code
    • hit command + enter (mac) or ctrl + enter (windows)
    • (alternatively, you can click “Run”)
  • if you don’t have highlighted code
    • hit command/ctrl + enter
    • R will run the line of code where your cursor is at (your cursor can be anywhere in the line)
    • R will also automatically move the cursor to the next line of code
    • This is a really handy way to run code line by line

R formatting basics

  • Use # to comment out text

  • Space and empty lines do not matter in R

  • R is case sensitive!

Sqrt(100)  # this will give you an error
  • Use ‘;’ to put multiple lines of code on the same line
2+4; 5*3
  • Can separate one line of code into multiple lines, as long as it is obvious that the previous line has not ended
# works
3 + 2 - 7 *
  1000 + 10 - 100
# does not work
3 + 2 - 7
* 1000 + 10 - 100

R objects; numbers and vectors

Creating an R object

  • Examples of R object: a number, a vector, a data frame, a function, etc.

  • To assign a number to an R object called “a”:

a=34
a = 34
a<-34
a <- 34
  • These lines of code are equivalent - personal habit
  • Very useful: you can print out an R object simply by running it
    • try: highlight “a” and run it

Vector: a collection of values

  • Example: Cereal$Name is a vector of 30 values
  • When creating a vector, use c( , ) for combined values
  • Exercise: record information for a cereal that is not in the Cereal dataset and save it as an R object called newCereal

R is case sensitive!

# these will give you errors
Plot(cereal$Carbs, cereal$Calories)
plot(cereal$Carbs, cereal$Calories)
plot(Cereal$carbs, Cereal$Calories)
  • You will see these errors pretty often:
    • Object `Reaction’ not found: check spelling; check where you thought you have created this object (did you actually create it by running the code?)
    • Could not find function `Plot’: check spelling; check if you have loaded relevant package
    • ‘x’ and ‘y’ lengths differ: separately print out x and y to check

Vector arithmetic

  • When you apply some operation to a vector, R will perform the operation to each element in the vector
2000 - Cereal$Calories
  • Important note: the vector Cereal$Calories is not changed and the new values are not stored (verify this); if you want to store the new vector, you need to assign it to a new R object or override an existing R object
remainCalories = 2000 - Cereal$Calories
  • When you do something like vector1 ± vector2, R will do the arithmetic operation element by element
    • if they have different lengths, R will give you a warning

Character strings

  • Put characters in double or single quotes
  • R knows certain characters, like col="red"
mycol="red"  #stores 'red' in an R object mycol
mycols=c('red','green','blue') #recall how to do vectors
  • mycol=red \(\rightarrow\) Error: object ‘red’ not found

Logical vectors

  • TRUE (or T) and FALSE (or F) are special logical characters when NOT in quotation
  • Numerically, R treats TRUE as 1 and FALSE as 0
  • Exercise: create a new vector, cats, that indicates if a student owns at least one cat or not
names <- c("Tom","Mary","Kate","James")
cats <- c(T,T,T,F)
as.numeric(cats)

  • Q: what will mean(cats) return?

  • Logical vectors are very useful for subsetting dataset. For example, to get all the names of students who own cats:

names[cats]

Logical vectors

  • Logical vectors can be created using logical operations: \(<, <=, >, >=, ==, !=\)
Cereal$Calories < 100
Cereal$Company == 'K'

  • IMPORTANT: do not confuse == and =!

  • which( ) will return the index of TRUE values

which(Cereal$Calories < 100)
which(Cereal$Company=='K')

Vector modification and subsetting

Append to a vector

  • The easiest way is to use c( , ) to combine vectors and/or a single element
# To append elements to a vector
names2=c("Aaron","Tom")
c(names,names2)

  • The function append is more general. Run ?append to get more information

  • Nothing is stored! Recall, to store, you have to assign the new vector to an R object. We’ll override the old vector to store the new vector:

names = c(names,names2)
cats = c(cats, F,F)
  • Run cbind(names,cats) (column bind) to double check

Subsetting: extract element(s) from a vector

  • Use the square bracket for subsetting
#To get the 2nd person's name
names[2]

#To get the 2nd and 3rd persons' names
#name[2,3] does not work! Always use c( , ) for vectors!
names[c(2,3)]

Q: what will names[c(2,2,2,3)] return?

Subsetting: extract element(s) from a vector

  • Can also subset use a vector of TRUE and FALSE
names[cats]

  • R returns elements corresponding to TRUE

  • Alternatively, you can use the which( ) function

Cereal$Name[Cereal$Protein>3]
Cereal$Name[which(Cereal$Protein>3)]

Delete from a vector

Use the minus sign to delete the corresponding elements from a vector

names[-2]
names[-c(2,3)]

Useful functions for creating vectors

c(1:5)
