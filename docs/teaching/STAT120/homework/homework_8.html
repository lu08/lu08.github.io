Part I: Writing functions

In this part, you will be asked to write R functions. You will be using these functions in Part II. Refer to Q1 of Part II to get a sense of how these functions should work. (We separate the two processes of writing and using functions here because this is what you would typically do: you would create a separate R file only for functions and then do the rest of the coding after “loading” the functions you have written.)

  1. Write a function, called f.getNA, that takes a vector as its argument, and returns the index of NA values in the vector. In addition, add a print option, defaulted to TRUE. If TRUE, the function will print how many NA values are found; if FALSE, nothing will be printed.
Show solution 
f.getNA <- function(x,print=T){
  result <- which(is.na(x))
  if(print){
     print(paste(length(result),'NA values are found')) 
  }
  return(result)
}

  1. Write a function, called f.topdiff, that takes two vectors of the same length and calculates the (element-wise) difference of the two vectors. The difference should be calculated in absolute value (i.e., difference between 1 and 5 is 4, difference between 5 and 1 is also 4; hint: you can use the function abs()). The function takes another argument, top (default to 1). If top is 3 (say), the function will return the indices of the top 3 biggest differences (don’t worry about handling ties). If top is an invalid value (like -3, 1.2, or a number larger than allowed), print an error message and return nothing.
Show solution 
f.topdiff <- function(x,y,top=1){
  #x <- HollywoodMovies$DomesticBO
  #y <- HollywoodMovies$WorldwideBO
  # top = 2
    #x <- c(90,100,100,90,50,80)
  #y <- c(100,90,50,40,55,80)
  
  diff <- abs(x-y)
  
  if(top %in% c(1:length(diff))){
    
    result <- data.frame(diff, index=c(1:length(diff))) %>%
    arrange(desc(diff)) %>%
    slice(1:top) %>%
    pull(index)
  
    ### OR ###
    # result <- order(diff,decreasing=T)[1:top]
    
    return(result)
  }else{
    print('Invalid top value')
  }
}
  1. Write a function, called f.plotn, that takes two vectors of the same length and generate a minimalistic scatterplot. Use plot() to do the scatterplot and set type to line (type=‘l’). Remove the x and y labels and the x and y axis. Set the line width (lwd) to 3. Add an argument to the function, color (default to ``black”), which controls the color of the scatterplot. This function only generates the plot and it does not need to have a return value.
Show solution 
f.plotn <- function(x,y,color='black'){
  plot(x,y,type ='l',col=color,xlab=NA,ylab=NA,xaxt='n',yaxt='n',lwd=3)
}
