  1. Reproduce the following two graphs with running.long (which is much easier than using the wide format!). They are essentially the same graph, but the first one is done with the base R boxplot function and the second one is done with ggplot2 (with theme_classic).
Show solution 
boxplot(running.long$Miles ~ running.long$Day,
        col='salmon',
        pch=16,
        xlab='Day',
        ylab='Miles')
Show solution 
running.long %>% 
  ggplot(aes(x=Day,y=Miles)) +
  geom_boxplot(fill='salmon') +
  theme_classic()

Part II

Take a look at the dataset USArrests in base R. Run the following code to extract the state names and store it as a separate variable in the data frame.

USArrests$state <- row.names(USArrests)

The following graph is generated using the maps package and based on the variable UrbanPop in the USArrests dataset. Reproduce this graph (you can visualize other variables in the USArrests dataset instead of UrbanPop, if you prefer). You can find sample code from Lecture 6 here.

Show solution 
library(maps)

USArrests$state <- row.names(USArrests) %>% tolower()
mymap <- map_data(map="state")

# Combine crime data to map data
mymap <- left_join(mymap, USArrests, by=c('region'='state'))

# Visualize
mymap %>%
  ggplot(aes(x=long,y=lat,group=group, fill=UrbanPop)) +
  geom_polygon(color='darkblue') +
  coord_fixed(1.4) +
  theme_void() +
  labs(fill='Urban population percentage') +
  scale_fill_gradient(low="yellow", high="blue")
