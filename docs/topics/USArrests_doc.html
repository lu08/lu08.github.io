USArrests: Violent Crime Rates by U.S. State

Description

USArrests contains statistics, in arrests per 100,000 residents, for assault, murder, and rape in each of the 50 U.S. states in 1973. It also includes the percentage of the population living in urban areas.

Format

A data frame with 50 observations and four variables:

Variable Type Description
Murder Numeric Murder arrests per 100,000 residents
Assault Numeric Assault arrests per 100,000 residents
UrbanPop Numeric Percent of the population living in urban areas
Rape Numeric Rape arrests per 100,000 residents

Note

USArrests contains the data as published in McNeil’s monograph. A review of Table 21 in the Statistical Abstracts of the United States 1975 reveals a transcription error for Maryland. McNeil also used the same “round to even” rule as R’s round() function, as noted by Daniel S. Coven (Arizona).

The example below corrects the Maryland value and restores the original half-percentage values.

Source

  • World Almanac and Book of Facts 1975 (crime rates).
  • Statistical Abstracts of the United States 1975, p. 20 (urban rates), possibly available online.

References

McNeil, D. (1977). Interactive Data Analysis: A Practical Primer. John Wiley & Sons. ISBN 978-0471026310.

See Also

The other state data sets in R’s datasets package.

# Difference between USArrests and its correction
USArrests["Maryland", "UrbanPop"]
[1] 67
UA.C <- USArrests
UA.C["Maryland", "UrbanPop"] <- 76.6

# Adjust the remaining percentages ending in .5
s5u <- c("Colorado", "Florida", "Mississippi", "Wyoming")
s5d <- c("Nebraska", "Pennsylvania")
UA.C[s5u, "UrbanPop"] <- UA.C[s5u, "UrbanPop"] + 0.5
UA.C[s5d, "UrbanPop"] <- UA.C[s5d, "UrbanPop"] - 0.5

# UA.C is now a corrected version of USArrests
